## Capability vocabulary and first-batch schema

| Internal `AllocationRepresentation` | Frozen `AllocationResult.representation_type` | `measure_definition` | Scope |
| --- | --- | --- | --- |
| FACE_FIELD | FACE_FIELD | face integrated | Case8 D_u only; existing DIAGNOSTIC_RERUN |
| CELL_FIELD | CELL_FIELD | cell integrated | Gate Acoustic, Pressure, Ungated |
| ANGULAR_SECTOR | ANGULAR_SECTORS | sector aggregated | Future Cylinder; description only |

`ANGULAR_SECTOR` is the requested internal capability name. `WIRE_REPRESENTATION` explicitly maps it to frozen plural `ANGULAR_SECTORS`; it never silently renames the public enum. Cylinder's frozen REGION_SCALAR band variant also remains a separate future result. No generic heatmap scientific representation is introduced.

`backend/models/allocation.py` implements only the first-batch discriminated field subset (`AllocationResult` root union of `FaceAllocation`/`CellAllocation`), frozen `AllocationSummary`, and its `SpatialCurve` dependency. RootModel serializes directly to the frozen result object, with no new wrapper or fields. Cylinder variants are deliberately not accepted by this subset; future Cylinder work must extend it using the already frozen sector/band variants, without altering the two field variants.

Mask means the existing `MaskSpec` in `backend/models/evidence.py`, reused without another mask DTO. SpatialDomain, MeasureConvention, ScientificResult/ProvenanceRef, Metric, ResourceSlot and ArrayRef likewise retain their existing models. `measure_definition`, `coordinate_convention` and `mask_definition` belong to an internal AllocationDescription, not new public fields; the frozen public equivalents remain domain.measure_convention, axes/geometry, MaskSpec.definition and ScientificDefinition.time_rule/spatial_rule.

Both windows use the prescribed initial front x_s(y)=.5+.0125·sin(8πy), inclusive abs(x−x_s(y))≤.08. Their domains, coordinates, array shapes, boundary scope and mask IDs differ. Do not share mask identity, recenter on evolved fronts, or substitute the saved derived face-to-cell average for authoritative native-face integration.

MaskSpec retains domain_refs, parameters (Fact for unknown values), index_sets/index_base, mask_array_refs, scope, verification and evidence. Case8 stored bool masks are authoritative; Gate's documented cell rule was checked in memory against frozen analysis. A future adapter may materialize that exact Gate rule only with explicit processing lineage and regression; it is never generated by the frontend. Mask arrays and coordinate arrays have their own result/header/unit, not the entropy array's header. UNKNOWN geometry cannot be asserted as known.

Future Cylinder sectors are 16 bins with 17 saved edges, interior-only cumulative channel sums, STATIC + TRAJECTORY_INTEGRATED [0,2], including native face/RK/time weights; sum(channel_at)=E_at_int. Angles use the saved edge convention/radian units. Sector bins cannot reconstruct a cumulative 2D field. The fixed A_u radial ±.16 front band is an independent REGION_SCALAR result, not a sector mask or a Case8/Gate window.

Summary total_budget/inside/outside are typed Metric slots. Preserve each metric's definition, unit, mask/scope and original sampling; integrated budget and fraction are distinct, fraction_format=FRACTION. Known integration intervals must agree, but original PER_STEP/TERMINAL/STATIC sampling is not rewritten to force equality. Zero denominator gives Fact NOT_APPLICABLE with ZERO_DENOMINATOR; missing resources have no value. SpatialCurve is spatial accumulation, not time history; unstored/unverified derivations remain MISSING, never an invented verified curve.

Every allocation/array preserves ScientificResult provenance (asset IDs, evidence, revisions, release Fact, source drift), original verification and limitations. Full Evidence keeps recorded/current data/method/dependency hashes and processing separate. Passing this check does not promote scientific status or prove current-code CFD reproduction.

## Optional adapter extension and service interface

`backend/adapters/allocation.py` declares `AllocationAdapterProtocol`; `backend/services/allocation.py` declares the matching `AllocationService` Protocol, with no concrete dispatch implementation. The existing Case8AdapterProtocol and Case8Adapter remain unchanged and conforming. Future Case8/Gate implementations opt into this separate allocation extension.

| Method | Arguments (plus keyword-only registry_revision=None) | Return / rule |
| --- | --- | --- |
| describe_allocation | experiment_id, config_id | AllocationDescription: capability, representation_type, measure_definition, coordinate_convention, mask_definition, ScientificDefinition; no numeric arrays |
| load_allocation_metadata | result_id | AllocationResult; refs/domains/summary/header, no allocation values |
| load_allocation_array | result_id, array_id | ScientificArray; registered allocation/mask/coordinate array only; array header equals metadata reference's scientific context |
| load_mask | mask_id | MaskSpec; bool values remain behind its controlled ArrayRefs |
| load_summary_metrics | result_id | AllocationSummary; preserve units/definitions/mask/measure and missing slots |

Resolve omitted revision once and pin all subsequent calls to that revision. Select sources through the existing read-only registry/guard; reject free paths, members, arbitrary q/time and interpolation. Future implementations must validate returned models and reference identity/dtype/shape/axes, check mask domain alignment, and preserve per-array provenance. Interfaces here perform no source I/O and enable no capability delivery.

Existing error semantics apply: Case8 A/B/C maps are known MISSING, unknown IDs are distinct; unsupported combinations remain UNSUPPORTED; undelivered code is FEATURE_NOT_ENABLED. SOURCE_DATA_DRIFT blocks numeric loads; SOURCE_CHANGED_DURING_READ rejects mixed reads; schema/read errors never yield empty success or zero arrays. Public DTOs expose no absolute locators.

Future routes retain C807, GATE02/GATE03, ARRAY01 and MASK01 without additions. No app factory, API catalog/OpenAPI/types, frontend, scientific source, CFD, registry delivery state or concrete loader was changed in Phase 6A.
